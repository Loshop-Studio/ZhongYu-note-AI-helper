## 二、识图与思考

- `do_vision()` 显式 `thinking: disabled` —— 思考模式**默认开启**，不传就等于开着，思维链会把预算烧光、正文为空
- `VISION_MAX_TOKENS = 6000`（原 1500）
- 思考四档：关 / 低 / 标准 / 最高，对齐官方 `reasoning_effort` 的 low / high / max
- 最高档 `max_tokens = 384000`（flash 输出上限就是 384K）
- 每轮回复末尾附 token 用量 + 折算金额（`cost_note` / `with_cost`）

## 三、硬性斜杠指令

**问题**：关键词匹配会让「什么是状态机」「今天日报里那个词啥意思」被当成指令劫持执行。

**方案**：指令必须带斜杠前缀。

```
/状态   /日报   /额度   /截图   /帮助   /仪表盘   /全功能   /思考 最高 ...
```

- 只认 `/` 和全角 `／`
- **不带斜杠一律当聊天**，不执行任何动作
- 带了斜杠但关键词没命中 → 才允许 DeepSeek 判意图（`ds_intent`）
- 忘了加斜杠、且标题恰好是整词（如「状态」）→ 回一句提醒，不执行
- 有图片的笔记不受影响（看图靠"有没有图"触发，不靠关键词）

## 四、上传失败不再重复执行

**10-25 事故根因**：回执上传失败后不记账 → 下一轮把同一条笔记当新指令 → 连执行带回执重来 → 连续 75 分钟。

| 修法 | 说明 |
|---|---|
| 执行完就记账 | `mark_handled()`，回执失败也绝不重跑 |
| 回执重试队列 | `state["replyQueue"]`，最多 20 条 / 6 小时，每轮补发 2 条 |
| 子进程预检查 | `_missing_child_file()`，日志直接点名缺哪个文件 |
| 异常日志带上下文 | 异常 + 完整命令 + 工作目录 |

## 五、系统保护（守护）

- 统一到 `app/guard.py`，设置界面共用这一份
- 开关 = **标志文件** `%LOCALAPPDATA%\ZhongYuToolBox\guard.enabled`（有=开）
- 频率 **30 分钟**（原 5 分钟），链路：计划任务 → `guard_run.bat` → `remote_guard.py`
- 卡死阈值 **动态**：`max(15 分钟, 3 × 检查频率)`（原来写死 15 分钟会误杀）
- 打包后脚本自动搬到 `%LOCALAPPDATA%\ZhongYuToolBox\`（onefile 的 `_MEIPASS` 路径不固定）
- 顺手清掉老任务「云笔记遥控器守护」

### 顺序坑（重要）

新 GUI 的 `load_conf()` 会把老 `full` 读成 `chat`，一保存就写盘。
如果那时跑的还是**旧 exe**，旧代码只认 `control`/`full`，读到 `chat` 会退化成「仅控制」。
**所以必须先换 exe，再打开设置界面点保存。**
