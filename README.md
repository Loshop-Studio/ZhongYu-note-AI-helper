# 云笔记遥控器

把云笔记当通道，远程操作家里那台电脑。

**场景**：人在学校，手里只有一台不能装软件的平板。想让家里的电脑截图、点个按钮、看看状态，唯一的双向通道就是云笔记。这个工具用「笔记标题」下发指令，家里的电脑定时扫描并执行，再把结果以笔记形式发回来。

## 能做什么

> ⚠️ **所有指令都必须以 `/` 开头**（全角 `／` 也认）。
> 不带斜杠的标题一律当聊天，不执行任何动作 —— 所以问「什么是状态机」不会再被当成指令。

**看情况**

| 指令 | 作用 |
|---|---|
| `/状态` | CPU / 内存 / 进程 / 磁盘体检（内存超 95% 会主动告警） |
| `/日报` | 今天和昨天各花了多少积分 |
| `/额度` | 积分估算，附 DeepSeek 账户余额 |
| `/DeepSeek余额` | 只看 API 账户余额 |
| `/截图` | 整屏截图，原图直出 |

**动一下**

| 指令 | 作用 |
|---|---|
| `/点 xxx` | 截屏 → 视觉模型两段定位 → 左键单击 → 回传点完的画面 |
| `/双击 xxx` | 同上，左键双击 |
| `/右键 xxx` | 同上，右键单击 |
| `/重启` | 真的重启 WorkBuddy（先杀全部进程再拉起） |
| `/开启workbuddy` | 没在跑就启动；在跑就回「本来就在跑」 |
| `/关闭workbuddy` | 结束所有 WorkBuddy 进程 |

**学习和问答**

| 指令 | 作用 |
|---|---|
| 发一张图（放在指令文件夹里的笔记） | 读题面、给解题步骤；也能读截图里的文字、看图表 |
| `/搜索 xxx` | 联网搜 5 条结果（DeepSeek Search API，每次约 5 厘） |
| 其他任意一句话 | 「普通模式」下交给 DeepSeek 回答 |

**调设置**

| 指令 | 作用 |
|---|---|
| `/仪表盘` | 把当前设置整理成图发回来（模式/频率/今日 agent 次数/上次巡检/思考强度） |
| `/全功能` / `/普通模式` / `/仅控制` | 切换运行模式（见下节） |
| `/频率 3` | 检查间隔改成 3 分钟（1~60） |
| `/字数 3000` | 回答长度上限（200~8000 token；只管「关/低/标准」三档） |
| `/思考 关` / `/思考 低` / `/思考 标准` / `/思考 最高` | 思考强度四档；「最高」档不限回答长度 |
| `/开启搜索` / `/关闭搜索` | 联网搜索开关 |
| `/校准 5000` | 设置积分基线 |
| `/重置 agent 次数` | 把今天用掉的全功能次数清零（每天 0 点也会自动归零） |
| `帮助` | 指令字典 |

## 三种模式

| 模式 | 关键词指令 | 聊天 | agent 编排 | 说明 |
|---|---|---|---|---|
| **仅控制** | ✅ | ❌ | ❌ | 只执行指令，不聊天、不跑 agent。最省钱最确定 |
| **普通模式** | ✅ | ✅ | ❌ | 原版行为：认得出关键词就执行，认不出就聊天。一句话只办一件事 |
| **全功能** | ❌ 关掉 | ✅ | ✅ | 一句话能组合多个动作，费钱、每条慢几秒 |

切换：发 `全功能` / `普通模式` / `仅控制`，或在设置界面里选。

> **升级说明**：2026-10-30 之前只有「仅控制 / 全功能」两种，那时的「全功能」
> 就是现在的**普通模式**。升级后老配置会自动迁移到普通模式、行为不变；
> 想用 agent 必须手动发一次「全功能」。

> 注：**仅控制不代表完全不碰 AI**。指令关键词认不出来时，仍会调一次 DeepSeek 做意图分类（约 1 厘），只是不会生成回答。

### 全功能（agent）模式怎么工作

你说一句话，模型自己决定调哪几个工具、按什么顺序办，最后把结果组织成一条回答。

**能用的工具（12 个）**：状态、日报、额度、DeepSeek 余额、仪表盘、帮助、
截图、单击、双击、右键、看图、联网搜索。

**配额（代码层硬限制，不是靠提示词求模型自觉）**：

- 每条指令最多调用 **3 次**工具（截图不计入）
- 其中联网搜索最多 **2 次**
- 截图单独最多 **3 张**
- 单条总时长 **90 秒**，超时中断并回复已完成的部分
- **每天最多 100 条** agent 任务；超了自动降级成普通模式（不会瘫痪），
  发 `重置 agent 次数` 可手动清零

**刻意不进 agent 的动作**：重启、关闭 WorkBuddy、以及所有改设置的操作
（思考档位 / 字数 / 频率 / 模式开关 / 搜索开关 / 校准）。
这些工具**根本不注册**，模型看不到就调不了，仍然只能靠关键词指令触发。

**点击的四层保护**：

1. 提示词明确禁止点删除 / 卸载 / 付款 / 提交这类目标
2. **原话匹配**：`target` 必须在你指令原文里出现过，模型不能自己编一个目标
3. **危险词**：目标含「删除 / 卸载 / 格式化 / 付款 / 转账 / 注销…」一律拒绝
4. **强制截图**：每次点击后自动截一张图，附在同一条回复里给你复核

## AI 能力

- **模型**：`deepseek-flash`（V4.1 Flash，原生多模态，能看图）
- **看图解题**：大图会自动切成 3×3 局部再放大，避免整图压缩后小字看不清
- **两段定位**：点按钮时先整屏粗定位，再把那一块从原图裁出来放大 2.5 倍精定位
- **思考强度**：关 / 低 / 标准 / 最高 四档（对齐 deepseek-flash 的 low / high / max）；
  最高档不限回答长度，最慢也最贵。**看图（拍照解题）固定不思考**，不受档位影响
- **每轮花费**：聊天 / 看图 / 搜索的回复末尾会附一行
  「本轮：输入 x + 输出 y = z token，花费约 ¥…」，按官网价折算，方便判断哪次问得贵
- **上下文记忆**：记住当天的对话，**第二天自动清空**（跨天重置，避免无限膨胀）

## 依赖

- Python 3.10+，需要 `tkinter`（标准库，但部分精简发行版没有）、`Pillow`、`pycryptodome`
- DeepSeek API 密钥（用于看图定位、意图分类、聊天、联网搜索）

```bash
pip install -r requirements.txt
```

## 配置

把 `zy_credentials.example.json` 复制一份改名成 `zy_credentials.json`，填上账号密码和服务器地址；
或者直接跑设置界面：

```bash
python app/setup_gui.py
```

界面里能改：

- **云笔记**：账号、密码、服务器地址
- **DeepSeek**：API 密钥
- **检查频率**：1~60 分钟
- **回答上限**：200~8000 token
- **思考强度**：关 / 低 / 标准 / 最高（四档）
- **模式**：仅控制 / 普通模式 / 全功能
- **联网搜索**：开关
- **开机自启动**：写进注册表 `HKCU\...\Run`
- **系统保护**：每 30 分钟检查一次进程，挂了（或卡死）就自动拉起。
  由计划任务 `ZhongYuRemoteGuard` 跑 `remote_guard.py`；
  **开关是一个标志文件** `%LOCALAPPDATA%\ZhongYuToolBox\guard.enabled`——
  有它才干活，删掉立刻停手，不需要管理员权限、也不用删任务
- **提示词**：普通模式的聊天提示词可自定义（全功能模式用的是内置调度提示词）

配置写在 `%LOCALAPPDATA%\ZhongYuToolBox\`，**不随仓库走**，也不会被提交。

## 运行方式

双击 `云笔记遥控器.exe`，右下角出现托盘图标，程序按设定间隔自己巡检。**关掉托盘图标 = 彻底停止**。

托盘右键菜单：

| 菜单项 | 作用 |
|---|---|
| 打开设置（双击图标也行） | 改账号、密钥、检查频率、模式等 |
| 暂停 / 继续 | 临时停止巡检（进程还在，随时恢复） |
| 开机自动启动 | 勾选后写注册表 |
| 打开日志 | 用记事本打开运行记录 |
| 退出（全停） | 停循环、退进程，彻底停止 |

源码方式运行：

```bash
python app/main.py            # 托盘常驻
python app/main.py --once     # 只巡检一次就退出（调试用）
python app/main.py --guard    # 守护模式：已在跑就静默退出（给计划任务用）
```

> 也保留了退回 Windows 计划任务模式的能力：`pythonw.exe -B app\control_bot.py`。

检查间隔建议 1~3 分钟。**token 会缓存 2 小时**（服务端 accessToken 的有效期），所以一分钟一轮也不会反复登录，风控压力很小。

## 指令文件夹怎么确定

程序**不会**去读整个根目录。定位顺序：

1. `config.json` 里的 `control_dir`（直接给文件夹 ID，最准）
2. `work_dir`（默认根目录）下名为 `control_subdir`（默认「控制」）的子文件夹
3. 都没有 → 尝试**自动创建**；创建失败就**本轮跳过**，并往根目录发一条「配置失败」告警（每小时最多一条）

第 3 条是硬性约束：宁可不动，也不会把普通笔记当成指令。
（早先版本在这里回退到了根目录，导致一轮误处理上千条笔记，已修正。）

> 注意：云笔记 App **新建笔记默认落在根目录**，需要手动移动到「控制」文件夹里，否则程序看不到。

## 安全设计

- 截图与远程点击**只在 07:00–23:00 生效**，避免人不在时被自动拍摄
- 点击只支持**左键单击 / 左键双击 / 右键单击**；不做拖拽、键盘输入、滚轮
- 点击前检查前台窗口，命中 UAC、注册表、磁盘管理、格式化等关键词直接拒绝
- 检测到锁屏 / 安全桌面时不执行
- 关闭 WorkBuddy 前检查 `zy_wake.lock`，5 分钟内有任务在跑就推迟
- 子进程全部无窗口启动（否则截图会把自己弹的控制台拍进去）
- 白名单执行器：**没有终端、没有 shell、不执行任何用户写的命令**

## 注意

- 请勿把账号密码或 API 密钥提交到仓库；本项目所有凭据都放在 `%LOCALAPPDATA%` 下
- 视觉模型返回的是**边界框中心**，两段定位后精度约 ±10–20 像素。点大按钮够用，点极小的图标建议先截一张确认位置
- 这套东西是给**自己的设备**用的应急通道，不适合当远程桌面
