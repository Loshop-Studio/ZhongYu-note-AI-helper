# 云笔记遥控器

把云笔记当通道，远程操作家里那台电脑。

**场景**：人在学校，手里只有一台不能装软件的平板。想让家里的电脑截图、点个按钮、看看状态，唯一的双向通道就是云笔记。这个工具用「笔记标题」下发指令，家里的电脑定时扫描并执行，再把结果以笔记形式发回来。

## 能做什么

**看情况**

| 指令 | 作用 |
|---|---|
| `状态` | CPU / 内存 / 进程 / 磁盘体检（内存超 95% 会主动告警） |
| `日报` | 今天和昨天各花了多少积分 |
| `额度` | 积分估算，附 DeepSeek 账户余额 |
| `DeepSeek余额` | 只看 API 账户余额 |
| `截图` | 整屏截图，原图直出 |

**动一下**

| 指令 | 作用 |
|---|---|
| `点 xxx` | 截屏 → 视觉模型两段定位 → 左键单击 → 回传点完的画面 |
| `双击 xxx` | 同上，左键双击 |
| `右键 xxx` | 同上，右键单击 |
| `重启` | 真的重启 WorkBuddy（先杀全部进程再拉起） |
| `开启workbuddy` | 没在跑就启动；在跑就回「本来就在跑」 |
| `关闭workbuddy` | 结束所有 WorkBuddy 进程 |

**学习和问答**

| 指令 | 作用 |
|---|---|
| 发一张图（放在指令文件夹里的笔记） | 读题面、给解题步骤；也能读截图里的文字、看图表 |
| `搜索 xxx` | 联网搜 5 条结果（DeepSeek Search API，每次约 5 厘） |
| 其他任意一句话 | 「全功能」模式下交给 DeepSeek 回答 |

**调设置**

| 指令 | 作用 |
|---|---|
| `仪表盘` | 把当前设置整理成图发回来（模式/频率/上次巡检/思考强度） |
| `全功能` / `仅控制` | 切换模式 |
| `频率 3` | 检查间隔改成 3 分钟（1~60） |
| `字数 3000` | 回答长度上限（200~8000 token） |
| `思考 高` / `思考 max` / `思考 关` | 思考强度 |
| `开启搜索` / `关闭搜索` | 联网搜索开关 |
| `校准 5000` | 设置积分基线 |
| `帮助` | 指令字典 |

## 两种模式

- **仅控制**（默认）：只认上面那些指令，其他话一律拒绝，不聊天、不答题
- **全功能**：认不出来的话交给 DeepSeek 回答，可以聊天、问问题

> 注：**仅控制不代表完全不碰 AI**。指令关键词认不出来时，仍会调一次 DeepSeek 做意图分类（约 1 厘），只是不会生成回答。

## AI 能力

- **模型**：`deepseek-flash`（V4.1 Flash，原生多模态，能看图）
- **看图解题**：大图会自动切成 3×3 局部再放大，避免整图压缩后小字看不清
- **两段定位**：点按钮时先整屏粗定位，再把那一块从原图裁出来放大 2.5 倍精定位
- **思考强度**：关 / 标准 / 最高三档（最高档解题更准，但更慢更费钱）
- **上下文记忆**：记住当天的对话，**第二天自动清空**（跨天重置，避免无限膨胀）

## 依赖

- Python 3.10+，需要 `tkinter`（标准库，但部分精简发行版没有）、`Pillow`、`pycryptodome`
- DeepSeek API 密钥（用于看图定位、意图分类、聊天、联网搜索）

```bash
pip install -r requirements.txt
```

## 配置

把 `zy_credentials.example.json` 复制一份改名成 `zy_credentials.json`，填上账号密码和服务器地址；
或者直接跑设置界面：

```bash
python app/setup_gui.py
```

界面里能改：

- **云笔记**：账号、密码、服务器地址
- **DeepSeek**：API 密钥
- **检查频率**：1~60 分钟
- **回答上限**：200~8000 token
- **思考强度**：关 / 标准 / 最高
- **模式**：仅控制 / 全功能
- **联网搜索**：开关
- **开机自启动**：写进注册表 `HKCU\...\Run`
- **系统保护**：每小时检查一次进程，挂了自动拉起（Windows 计划任务）
- **提示词**：全功能模式的聊天提示词可自定义

配置写在 `%LOCALAPPDATA%\ZhongYuToolBox\`，**不随仓库走**，也不会被提交。

## 运行方式

双击 `云笔记遥控器.exe`，右下角出现托盘图标，程序按设定间隔自己巡检。**关掉托盘图标 = 彻底停止**。

托盘右键菜单：

| 菜单项 | 作用 |
|---|---|
| 打开设置（双击图标也行） | 改账号、密钥、检查频率、模式等 |
| 暂停 / 继续 | 临时停止巡检（进程还在，随时恢复） |
| 开机自动启动 | 勾选后写注册表 |
| 打开日志 | 用记事本打开运行记录 |
| 退出（全停） | 停循环、退进程，彻底停止 |

源码方式运行：

```bash
python app/main.py            # 托盘常驻
python app/main.py --once     # 只巡检一次就退出（调试用）
python app/main.py --guard    # 守护模式：已在跑就静默退出（给计划任务用）
```

> 也保留了退回 Windows 计划任务模式的能力：`pythonw.exe -B app\control_bot.py`。

检查间隔建议 1~3 分钟。**token 会缓存 2 小时**（服务端 accessToken 的有效期），所以一分钟一轮也不会反复登录，风控压力很小。

## 指令文件夹怎么确定

程序**不会**去读整个根目录。定位顺序：

1. `config.json` 里的 `control_dir`（直接给文件夹 ID，最准）
2. `work_dir`（默认根目录）下名为 `control_subdir`（默认「控制」）的子文件夹
3. 都没有 → 尝试**自动创建**；创建失败就**本轮跳过**，并往根目录发一条「配置失败」告警（每小时最多一条）

第 3 条是硬性约束：宁可不动，也不会把普通笔记当成指令。
（早先版本在这里回退到了根目录，导致一轮误处理上千条笔记，已修正。）

> 注意：云笔记 App **新建笔记默认落在根目录**，需要手动移动到「控制」文件夹里，否则程序看不到。

## 安全设计

- 截图与远程点击**只在 07:00–23:00 生效**，避免人不在时被自动拍摄
- 点击只支持**左键单击 / 左键双击 / 右键单击**；不做拖拽、键盘输入、滚轮
- 点击前检查前台窗口，命中 UAC、注册表、磁盘管理、格式化等关键词直接拒绝
- 检测到锁屏 / 安全桌面时不执行
- 关闭 WorkBuddy 前检查 `zy_wake.lock`，5 分钟内有任务在跑就推迟
- 子进程全部无窗口启动（否则截图会把自己弹的控制台拍进去）
- 白名单执行器：**没有终端、没有 shell、不执行任何用户写的命令**

## 注意

- 请勿把账号密码或 API 密钥提交到仓库；本项目所有凭据都放在 `%LOCALAPPDATA%` 下
- 视觉模型返回的是**边界框中心**，两段定位后精度约 ±10–20 像素。点大按钮够用，点极小的图标建议先截一张确认位置
- 这套东西是给**自己的设备**用的应急通道，不适合当远程桌面
